# Tig Wave

Use this skill to create or update Tig waves.

## Wave requirements

- Name the repo startup files a new agent should read.
- Define a product-neutral goal when the repo is shared infrastructure.
- Identify affected crates/packages and consumer repos.
- Identify governing VTRACE/spec/role-review artifacts, or mark them out of
  scope.
- Break the wave into small pulses.
- Include validation expectations for every pulse.
- Record non-goals.
