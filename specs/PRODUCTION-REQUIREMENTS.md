Primary bytes alone are not the rebuild closure. A container may select an opaque
native scene document and several named control streams. A source revision also
needs its exact raw instance, definition and authored schema bytes. A job owner
must preserve all of these, while keeping semantic completeness, custody and
source/job admission separate.

Add an explicit caller-admitted Payloads::Named selector with a selected-object
flag and an exact set of required stream slots. It may combine the selected
document and named streams. There is no extension/group/filename guessing,
recursive payload scan, historical fallback or copied authored dependency list.
Missing required selections and unsupported payload meaning refuse the production
requirements query, including on containers. Existing selectors keep their meaning.
The profile/admission digest includes the selector; the experimental native record
and definition envelopes and existing full binding-digest framing are unchanged.

Graph::production_requirements requires complete Production-only reference
coverage and every node's declared payload meaning. It returns disjoint-purpose
sets (which may share byte identity): primary payloads from Primary nodes,
control payloads from Container nodes and exact bound interpretation documents
from every visited node. An Output node cannot contribute payloads to this set,
including when used as a root; production target output edges still refuse.
Output metadata may describe an output's dependencies without consuming its bytes.
Repeated objects are deduplicated; contradictory sizes invalidate the graph.
Delivered/selected output bytes still need their separate output-custody claims;
excluding them from build inputs never withdraws their storage obligation.

These are exact scoped declared requirements, not global reference counts or
proof that opaque native semantics are fully consumed. An admitted producer must
validate that its sole declarative source accounts for every actual input. No
payload is read or retained by querying; source archives and payload providers
remain separate. Durable root/job ownership, complete claims, metadata/provider
availability, consumed-property recipes, custody and fresh removal fencing are
still required. Neither an empty set nor an old/new difference authorizes eviction.

The synthetic source/job integration composes these object sets and a native
archive pointer into the existing immutable Tree, then uses the existing source
journal's prepare/adopt/predecessor transitions. A registered render job keeps its
old root after main advances and retires its own predecessor. SQLite metadata is
explicitly finished/reopened and source interpretation replays with Git/working
metadata moved aside. The fixture deliberately has no payload bytes: surviving
root obligations do not prove media custody or complete job/source enrollment.
