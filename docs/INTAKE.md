# Dependency intake

Tig builds as a standalone Cargo workspace. No portfolio checkout, absolute
machine path, renderer or project repo is a runtime dependency. Optional typed
assets depend on byte identity; basic Git/LFS remains independent.

ROLES and PITFALL development checkers are vendored unmodified with upstream
licenses and verified pins. VTRACE is a local engineering discipline, not an
external runtime or certification claim. NOTICE.md records source donors and
dependency notices. Preserve attribution when generalizing examples.

Use Cargo.lock and explicit features. Providers require capability, operational,
recovery and license review with isolated fixtures. Do not adopt a service or
scripting platform merely to satisfy a scaffold. Consumer enrollment, credentials
and operational evidence remain owner-managed.
