# Tig mitigation register

Each mitigation is a target obligation, not a claim of an implemented fix. The
13 pure handoff tests offer partial mechanism evidence only and cannot close any
entry here. Owners match repo-local role slugs. Closure requires exact positive,
negative and recovery/provider evidence plus scoped review.
